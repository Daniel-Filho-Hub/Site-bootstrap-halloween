# 🎃 Spooky Central

<p align="center">
  <strong>Seu portal de Halloween!</strong>
</p>

Um site temático desenvolvido com **HTML, CSS e Bootstrap**, trazendo informações, curiosidades e conteúdos relacionados ao Halloween e ao folclore brasileiro.

## 👻 Sobre o projeto

O **Spooky Central** é um portal temático criado para apresentar conteúdos relacionados ao Halloween de maneira interativa e visualmente atrativa.

O site reúne dicas de fantasias, receitas de doces, curiosidades sobre o Dia do Saci e informações sobre clássicos do cinema de terror, utilizando uma identidade visual inspirada no universo sombrio do Halloween.

## 🚀 Funcionalidades

- **Menu de navegação:** acesso às diferentes seções do portal.
- **Banner principal:** destaque visual para a temática do Halloween.
- **Alerta informativo:** aviso sobre a comemoração do Halloween.
- **Cards interativos:** apresentação de conteúdos sobre fantasias, doces e folclore.
- **Medidor de medo:** barras de progresso para representar diferentes níveis de terror.
- **Clássicos do terror:** lista de filmes clássicos com seus respectivos anos de lançamento.
- **Perguntas frequentes:** seção expansível com curiosidades sobre o Halloween.
- **Campo de busca:** interface para pesquisa de conteúdos.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estruturação das páginas |
| CSS3 | Estilização e identidade visual |
| Bootstrap 5 | Layout responsivo e componentes visuais |
| JavaScript | Interatividade dos componentes |

## 🎨 Identidade visual

O projeto utiliza uma interface com temática de Halloween, destacando:

- Fundo escuro para criar uma atmosfera sombria.
- Cores laranja, amarelo, vermelho e verde nos elementos visuais.
- Imagens temáticas relacionadas ao Halloween.
- Cards e componentes do Bootstrap para organizar os conteúdos.
- Layout responsivo para diferentes tamanhos de tela.

## 💻 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd SEU-REPOSITORIO
   ```

3. Abra o arquivo `index.html` no navegador.

   Você também pode utilizar a extensão **Live Server** no Visual Studio Code para visualizar o site durante o desenvolvimento.
